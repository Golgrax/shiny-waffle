# Bionic Duo Portfolio

A professional portfolio for **Karl Benjamin R. Bughaw** and **Jhanric Hanamichi C. Pablo**. This repository contains a Python Flask application that serves a high-performance, statically exported Next.js frontend.

## Overview

This project showcases the technical synergy between systems engineering and creative frontend development. The interface follows the "Bionic Design 2026" aesthetic, characterized by industrial brutalism, technical clarity, and dynamic mechanical layering.

## Core Components

- **Flask Backend:** A lightweight Python server (`app.py`) responsible for serving the static assets and handling routing.
- **Static Assets:** The `static/` and `templates/` directories contain the optimized HTML, CSS, and JavaScript generated from the Next.js build.
- **Source Archive:** The complete React/Next.js development environment is preserved within `react_source.zip`.

## Technical Specifications

- **Backend:** Python 3.x, Flask
- **Frontend Framework:** Next.js (Statically Exported)
- **Styling:** Tailwind CSS v4, Industrial Brutalist Design System
- **Animations:** Framer Motion, WebGL Raycast Shaders
- **Typography:** Custom Industrial Typefaces (Asix Founder, Giga, Roadam)

## Installation and Deployment

To deploy the application locally:

1. **Ensure Python 3 is installed.**
2. **Install Flask:**
   ```bash
   pip install flask
   ```
3. **Execute the application:**
   ```bash
   python3 app.py
   ```
4. **Access the interface:**
   Navigate to `http://127.0.0.1:5000` in your web browser.

## Project Structure

- `app.py`: Entry point for the Flask application.
- `static/`: Contains compiled CSS, JavaScript, and media assets.
- `templates/`: Contains the exported HTML documents for each route.
- `react_source.zip`: Complete original source code for development and modification.
